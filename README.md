## 🏛️ Architectural Overview

ForgeEnergy is designed with an uncompromising privacy architecture:
- **SSG Core:** [Astro](https://astro.build) delivers instantaneous sub-100ms first-contentful-paint (FCP) and optimal SEO indexing.
- **Interactive Islands:** [React](https://react.dev) powers the synchronized state machines, breathing visualizer, Web Audio harmonic oscillators, and keyboard stealth listeners.
- **Styling & Aesthetics:** Custom Tailwind CSS palette engineered for deep calm and focus:
  - Sage Green (`#8B9A6E`): Primary action and progress accent
  - Cream Canvas (`#F7F2EB`): Primary ambient background
  - Warm Sand (`#EAE2D6`): Card containers and interactive surfaces
  - Soft Gray (`#EEEEEE`): Subtle tactile dividers
  - Deep Obsidian (`#0E0F0D` / `#181A15`): Low-stimulation dark mode
- **100% Zero-Server Storage:** All streaks, ledger logs, and notes reside strictly inside browser `localStorage`. No databases, cookies, external telemetry, or analytics tracking.

## 🛠️ Local Development & Build

### Prerequisites
- Node.js 18+ (tested on Node v24)
- npm 9+

### Commands

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build static production assets
npm run build

# Preview static production build
npm run preview
```

Static build artifacts are output to `./dist/` ready for immediate deployment to GitHub Pages.
